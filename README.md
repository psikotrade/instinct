# INSTINCT — website prototype v0.2

Static, responsive prototype for the INSTINCT market-intelligence brand.

## Included
- Premium dark/light financial visual system
- Responsive navigation
- Interactive Market Pulse tabs: IHSG / Macro / Global
- Research category filters
- Strategy / asset-allocation section
- Academy section
- Waitlist interaction (front-end demo)

## Run locally
Open `index.html` in a modern browser.

## Deploy
This folder can be deployed to any static hosting provider such as Vercel, Netlify, GitHub Pages, or Cloudflare Pages.
